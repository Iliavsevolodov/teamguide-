# ⚡ #СуперГерои — интерактивный гайд Greenway

Мобильный сайт-методичка **«Искусство приглашать людей»** для команды #СуперГерои.

## Что внутри

- 10 оформленных обучающих разделов с навигацией.
- Формула сильного приглашения из 7 шагов.
- Два голосовых скрипта: для новичка и опытного партнёра.
- Четыре первых сообщения под разные аудитории с кнопками копирования.
- Пять распространённых возражений и короткие ответы.
- Маршрут общения от первого контакта до старта.
- Интерактивный план практики на 7 дней.
- Чек-лист готовности приглашения из 9 пунктов.
- Сохранение прогресса чек-листов в браузере.
- Адаптивная мобильная версия и печать/сохранение в PDF.

## Дизайн

Фирменный **ILYA VSEVOLODOV — AIRY LUXURY EDITORIAL**: чистый белый и тёплый айвори, аккуратная типографика, ровная сетка, сдержанные жёлтые акценты и много свободного пространства. Сайт адаптирован для смартфонов; тяжёлые декоративные элементы и нижняя навигационная панель убраны.

Сайт сделан на чистых **HTML + CSS + JavaScript** без сборщиков, платных сервисов и зависимостей. Шрифты Manrope и Inter Tight загружаются через Google Fonts; без интернета используются системные шрифты.

## Публикация через GitHub Pages

1. Открой [репозиторий](https://github.com/Iliavsevolodov/teamguide-).
2. Перейди в **Settings → Pages**.
3. В блоке **Build and deployment** выбери **Source: Deploy from a branch**.
4. Укажи **Branch: main**, папку **/(root)** и нажми **Save**.

После публикации сайт будет доступен по адресу:

**https://iliavsevolodov.github.io/teamguide-/**

Первое появление сайта может занять несколько минут после включения GitHub Pages. Последующие коммиты в ветку main будут обновлять опубликованный сайт автоматически.

## Как изменить сайт

- \`index.html\` — тексты, разделы, структура, скрипты.
- \`styles.css\` — цветовая схема, типографика, адаптивность и печать.
- \`app.js\` — кнопки копирования, вкладки, навигация, интерактивные чек-листы.
- \`.nojekyll\` — публикует сайт как обычную статику без обработки Jekyll.

Для локального просмотра открой \`index.html\` в браузере. При копировании сообщений из локального файла браузер может потребовать разрешение; после публикации на HTTPS копирование работает стандартным Clipboard API.
